## 🚀 প্রধান বৈশিষ্ট্যসমূহ (Key Features)

- **📱 পরিচ্ছন্ন ৩-ডট ড্রয়ার মেনু (Clean Mobile Navigation):** সমস্ত অ্যাকশন এবং টুল স্ক্রিনের ওপর কোনো বাধা সৃষ্টি না করে থ্রি ডট মেনুর ভেতর সুবিন্যস্ত।
- **🔍 ইনস্ট্যান্ট মেনু সার্চ:** বাংলা ও ইংরেজিতে পছন্দের কফি বা পেস্ট্রির নাম লিখে ১ ক্লিকে খুঁজে নেওয়ার সুবিধা।
- **🛒 কার্ট ও অনলাইন চেকআউট:** স্বয়ংক্রিয় ডিসকাউন্ট হিসেব, ক্যাশ অন ডেলিভারি, বিকাশ ও নগদ পেমেন্ট মেথড।
- **📦 লাইভ ৫-ধাপ অর্ডার ট্র্যাকার:** অর্ডার গ্রহণ থেকে ডেলিভারি পর্যন্ত বাস্তব সময়ের ট্র্যাকিং ও হোয়াটসঅ্যাপ মেসেজ পাঠানো।
- **📜 অর্ডারের ইতিহাস (Past Orders):** ব্রাউজার লোকাল স্টোরেজে সংরক্ষিত বিগত সব অর্ডারের মেমো তালিকা।
- **📄 ডিজিটাল PDF রসিদ ও মেনু:** ১-ক্লিকে অফিশিয়াল ক্যাশ মেমো এবং সম্পূর্ণ মেনু কার্ড PDF ডাউনলোড।
- **🌙 ডার্ক / লাইট মোড:** যেকোনো সময় চোখের আরামদায়ক থিম পরিবর্তন।
- **⚙️ লাইভ ওয়েবসাইট কাস্টমাইজার:** কোড না ছুঁয়েই মালিক ও শপের নাম, ফোন নম্বর, দাম ও নোটিশ পরিবর্তন করার অ্যাডমিন সুবিধা।

## 💻 লোকাল মেশিনে রান করার নিয়ম (How to Run Locally)

1. **রিপোজিটরি ক্লোন করুন:**
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   cd coffee-shop
   ```

2. **ডিপেন্ডেন্সি ইনস্টল করুন:**
   ```bash
   npm install
   ```

3. **ডেভ সার্ভার চালু করুন:**
   ```bash
   npm run dev
   ```
   এরপর ব্রাউজারে `http://localhost:3000` ওপেন করুন।
